# AvenoxBeyin V3.11.1

Sürüm kanalı bu depoya çevrildi. İşlevsel değişiklik yok.

## Mevcut kullanıcı: bir kez güncelle

```sh
python3 beyin.py update        # macOS / Linux
py -3 beyin.py update          # Windows
```

## Değişiklik

### Release kanalı

`beyin.py update` artık güncellemeleri `Ahmet53535353/MindFork` deposundan arar,
`avenoxai/avenoxbeyin`'den değil. Bu deponun upstream'e yayınlama yetkisi yok
(`admin:false, push:false`); 3.7.1–3.10.0 release'lerinin tamamı bakımcının.

Ayrıntılı gerekçe: `knowledge/concepts/release-kanali-upstream-forkta-yayinlanmaz.md`.

**Bedel:** upstream'in yeni sürümleri bu build için otomatik görünmez olur. Upstream
bir sürüm yayınladığında aynı paket bu depoya da yüklenmelidir.

İki sabit ayrı iş yapar ve birlikte değişti: `OFFICIAL` "en yeni sürüm hangi depoda
aranır" sorusunu yanıtlar (`check()` onu okur), `OFFICIAL_WEBS` "hangi depoların asset
URL'leri güvenilir" sorusunu yanıtlar (indirme doğrular). Yalnızca listeye eklemek
`check()` davranışını değiştirmezdi.

Güvenlik sınırı daraltılmadı: upstream'in iki adı kabul edilmeye devam eder, fork'un
komşu adları (`MindFork2`, `mindfork`, küçük harf varyantı, başka kullanıcı) reddedilir.
