# AvenoxBeyin V3.7.0

Bu sürümün ana konusu oturum başı bağlamının istemciye gerçekten ulaşması. Claude Code 10.000 karakteri, Codex 10.000 baytı geçen hook bağlamını dosyaya taşıyor ve modele yalnız bir parçasını gösteriyor; 3.6.0'daki geniş açılış bütçesi önerisiyle Last-Session, Threads ve Journal otomatik bağlamdan düşüyordu (#175). Artık iki istemcide de bağlam bu sınırın altında kalıyor. Ayrıca gizli nota bağlı receipt'in oturum başına girmesi kapatıldı, `companion-compact` yeniden yazma yolunda tam yedek alıyor, `recover` başarılı bir V2 geçişinden sonra takılmıyor ve iki isteğe bağlı özellik geldi: paralel oturum bildirimi ve kullanım raporu.

## Mevcut kullanıcı: bir kez güncelle

Vault klasöründe macOS / Linux:

```sh
python3 beyin.py update
```

Windows:

```powershell
py -3 beyin.py update
```

Ajanına "beynimi güncelle" demen de aynı komutu çalıştırır. Güncellemeden sonra yeni istemci oturumu aç. V3.6.0 kurulumundan güncelleme `trust_review_required: false` bildirir. Yeni kurulum için `beyin-v3-3.7.0.zip` ve yanındaki `.sha256` dosyasını indir; GitHub'ın Source code arşivini kullanma.

`--companion-context-chars 24000` ayarladıysan Claude Code ve Codex'te bağlam yine 9.500'de tutulur; ayarı değiştirmen gerekmez. Diğer istemcilerde ayar olduğu gibi geçerli.

## Yenilikler

### Oturum başı bağlamı

- **İstemci sınırları:** Claude Code (10.000 UTF-16 karakter) ve Codex (10.000 UTF-8 bayt) için açılış ve tur bağlamı 9.500'de tutuluyor; Türkçe harfler yüzünden Codex sınırı aşılırsa bağlam küçük bütçeyle yeniden üretiliyor, böylece sondaki bölümler kaybolmuyor. Skill önerisi 24.000'den 8.000'e indi. `.codex/hooks.json` değişmedi, Codex hook güveni etkilenmiyor (#175, #176, #186).
- **Kurallar.md:** Açılışta önce bütün kural cümleleri geliyor; payı yetmezse `**neden:**` / `**gerekçe:**` kısımları atılıyor ve sayısı yazılıyor. V2 şablonundaki "ilk 60 satır" paragrafı açılış görünümünden çıkıyor; dosyana dokunulmuyor (#177, #184).
- **Knowledge map payı** yer bolken boş alanla ölçekleniyor; companion kırpılırken eski payında kalıyor (#146, #167).
- **Son receipt** başlığı kaynak dosyayı adlandırıyor ve yalnız tam başlığıyla ekleniyor (#147, #174); dosya zamanına göre değil `created_at` değerine göre seçiliyor, `git pull` sırayı bozmuyor (#112, #186).
- **Gizlilik:** gizli (`visibility: private`) ya da güvenilmez bir nota bağlı receipt artık vault içindeki SessionStart'a da girmiyor; köprüyle aynı kural (#186).

### Güncelleme, geçiş ve kurtarma

- `recover`, başarılı bir V2 geçişinden sonra yarım kalan güncellemede bir not değişince `source or legacy state changed during migration` ile takılmıyor. Gerçek ilk geçişte kaynak kontrolü aynen duruyor. Daha eski bir güncellemede zaten takılı kalan vault için: önce `beyin.py rollback`, sonra `beyin.py update` (#181, #182).
- AGENTS bloğu makine yolu taşımıyor (`python3 beyin.py sync`); iki makinede aynı çıkıyor ve git ile gelen yeni blok öbür makinenin güncellemesini durdurmuyor (#112, #186).

### Companion arşivi

- `companion-compact` `needs_rewrite` derse, ajan dosyayı yeniden yazmadan önce tam metin aylık `Arşiv/<Dosya>-YYYY-MM.md` dosyasına kelimesi kelimesine yazılıyor; kısmi taşıma sonrası hala sınırı aşan dosyada da. `--dry-run` hiçbir şey yazmıyor ve yedek varmış gibi davranmıyor (#168, #171).

### Senkron

- Frontmatter'da tek seviyeli iç içe YAML (`metadata:` altında `anahtar: değer`) okunuyor; Claude auto-memory gibi notlar artık indekse giriyor. `visibility`, `trust` gibi gizlilik anahtarları iç içe yazılırsa uygulanmadıkları için not uyarıyla dışarıda kalıyor (#179, #180).

### İsteğe bağlı yeni özellikler

- **Paralel oturum bildirimi:** aynı vault'ta başka bir oturum açıksa ilk istemde tek satırlık uyarı. Varsayılan kapalı: `python3 beyin.py preferences --parallel-sessions on`. İşaretler runtime klasöründe, istem metni yazılmıyor (#170, #183).
- **Kullanım raporu (geliştirici aracı):** `scripts/evaluate_v3_usage.py`, Claude Code transkriptlerinden enjekte edilen notların sonradan açılıp açılmadığını salt okunur sayıyor; yayın paketine girmiyor. Ayrıntı [USAGE-REPORT.md](https://github.com/avenoxai/avenoxbeyin/blob/main/docs/v3/USAGE-REPORT.md) (#172, #185).

### Test ve ölçüm

- Test paketi üst ortamdaki `BEYIN_*` ayarlarını devralmıyor (#169, #186).
- Arama benchmark raporu temizlendi, `daily/` dışlanmış kontrol satırı eklendi (#173).

## Doğrulama

- Yayından önce 871 V3 testi Python 3.11 ve 3.14'te, kullanıcı `BEYIN_*` ayarları açıkken de geçti; donmuş retrieval kapısı (development 10/10, holdout 6/6) geçti. Yayın hattı aynı ZIP'i Windows, macOS ve Linux'ta doğrular.
- Yerelde yayınlanmış V3.6.0 paketiyle kurulan sentetik bir vault bu sürüme güncellendi (`trust_review_required: false`) ve `verify_v3_release.py` V3.6.0 tabanıyla geçti. Paralel oturum bildirimi ve geniş açılış bütçesi açıkken V3.6.0'a rollback yapıldı; `doctor` ve SessionStart hook'u hatasız çalıştı.
- Gerçek Claude Code oturumunda 24.000 ayarıyla SessionStart artık dosyaya taşınmadan 9.500 karakter olarak geliyor.
